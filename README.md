🛠️ Tech Stack & Implementation Details

In terms of technology, I decided to build this project from scratch without using any large-scale UI frameworks. This allowed me to learn and implement a lot of exciting technologies and methods.

The website uses HTML5 semantic elements to ensure accessibility, proper document structure, and SEO optimization.

CSS3 is used extensively to create high-quality custom UI components. I have utilized CSS variables, Flexbox and Grid layout, backdrop blur, and transitions. Multiple CSS keyframe animations help to engage users and highlight important elements.

JavaScript ES6 is used to implement the dynamic behvaior. Some of the key features include:

IntersectionObserver for progress bar animations

DOM and event manipulation to implement popup modals and mobile menu

LocalStorage API to persist theme preference

Asynchronous typing loop

🔥 My Favorite Part

Probably the most technically challenging and time-consuming part of the website was implementing the custom dark/light theme switcher. As a user prefers the light/dark version of the website, a backdrop filter is applied to the page elements to give it a glassmorphism look.
Instead of using any third-party UI framework or utility library, I have implemented all theming-related features manually using CSS variables and JS. All the complex animation and transition logic is handled natively by the browser, which makes the code performant and efficient.
